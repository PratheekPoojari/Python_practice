# Python_practice

Practice repo for learning Python fundamentals through CS50P, freecodecamp.org, etc...

## Contents

### CS50P
- `Lecture 0` — Learnt about string functions, how to create custom functions, types of variables, and built a basic CLI calculator(uses sys.exit(0)) to exit the program.
- `Lecture 1` — Learnt about simple if-else, even/odd checking and 'match case'. 
- `Lecture 2` — Learnt about 'for' and 'while' loops; 'lists', 'Dictionaries', and 'List of Dictionaries'; 'nested loops' to print 2D structure of '#'.
- `Lecture 3` — Uses 'try', 'except' and 'pass', to make sure that exceptions are handeled(ValueError and NameError).
- `Lecture 4` — General Approach towards libraries, APIs and how to install and import 3rd party and our own libraries.
- `Lecture 5` — Learnt about programs to test other programs using pytest, assert keywords.
- `Lecutre 6` — Learnt File I/O(.txt and .csv). Used csv library for csv fil operations. Used pillow library to a `customs.gif` using 'N' number of .gif files.
- `Lecture 7` — Learnt about Regular Expressions(re), the 're' library and it's various functions. re.search(), re.sub() and string method replace.
- `Lecture 8` — Learnt about Various OOPs concepts such as Classes, dunder methods, properties such as getter/setter using decorators, inheritance, OperatorOverloading.
- `Lecture 9` — Learnt about more data types like sets, global variables, constants and various tools like type hints, return types, argparse lib, unpacking(*args, **kwargs),
                map, filter, list and dict comprehensions, enumerate and generators(yeild).
